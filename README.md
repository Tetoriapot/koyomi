# 暦 — 年齢・西暦和暦早見

「あの年、何歳だった？」をすぐに調べられる、完全クライアントサイドの日本語Webツールです。Vite + TypeScript + Vanilla DOMで実装しています。実行時の外部API、CDN、外部フォント、分析ツール、データベースは使用しません。

## 起動とビルド

Node.js 22.12以降（Node.js 24推奨）とnpmを用意します。

```sh
npm install
npm run dev
```

表示されたローカルURLを開いてください。テストと本番ビルドには次のコマンドを使います。

```sh
npm run test
npm run build
npm run preview
```

- `npm run test`：Vitestの単体テスト。現在時刻に依存する検証は2026年9月25日を明示して固定しています。
- `npm run test:watch`：テストの監視。
- `npm run build`：TypeScriptの厳密な型検査後、`dist/` に静的ファイルを生成。
- `npm run preview`：本番ビルドをローカルで確認。
- 初回の依存関係の取得にはネット接続が必要です。通常のアプリ利用にバックエンドは不要です。

Vite / esbuildの起動には子プロセス実行権限が必要です。制限された開発環境で `spawn EPERM` となる場合は、その環境の実行許可を確認してください。

## 使える機能

- 西暦と明治・大正・昭和・平成・令和の相互変換。日付単位の改元境界判定。
- 生年からの年齢幅、生年月日からの満年齢、任意の基準日。
- 「この年に何歳？」と「この年齢になるのは？」。
- 2～4人の年齢比較。呼び名付きの入力、全組み合わせの満年齢の差、比較結果のコピー。
- 年齢から候補の生年を計算。候補を選ぶと年表を表示。
- 誕生～100歳と現在の年齢年表。10年ごと／1年ごとの切替。
- 学年早見、十二支、長寿の節目。
- 西暦・和暦・年齢・年表のコピー、共有URLのコピー。
- 320pxからのレスポンシブ表示、システム連動／ライト／ダークの3段階テーマ。
- PWA manifest、アイコン、オフライン用Service Worker。
- ラベル、キーボード操作、フォーカス表示、状態の読み上げ、動きを抑える設定に対応。

初回は「昭和42年生まれ」と、その計算結果を入力例として表示します。入力欄の下に入力例であることを明示し、入力を書き換えると案内を非表示にします。利用者の履歴ではありません。

画面は「変換」「年齢計算」「年齢比較」「年表」「学年」の5つのタブに分かれています。最初は入力欄と変換結果を表示し、他の機能はタップ・クリックで切り替えます。タブを切り替えても入力内容は保持されます。「年齢の基準日」は閉じた状態でも日付を表示し、開くと変更できます。入力例、干支、呼び名の入力も必要なときに開けます。キーボードでは左右矢印・Home・Endでタブを移動できます。

右上の「更新履歴」と「Help／使い方」はポップアップで表示します。Helpには操作、和暦の略称、計算仕様、共有についての説明をまとめています。「×」、背景のタップ・クリック、Escキーで閉じられ、入力内容は保持されます。長い内容はポップアップ内でスクロールできます。更新履歴の内容は `src/ui/information.ts` で管理します。文字はブラウザーの拡大機能で大きくできます。

## 入力形式

| 種類 | 入力例 |
| --- | --- |
| 西暦 | `1998`、`1998年`、`西暦1998年` |
| 生年 | `1998年生まれ`、`1998年生`、`1998生` |
| 和暦 | `平成10年`、`H10`、`h 10`、`昭和42年生まれ` |
| 元年 | `令和元年`、`R1`、`平成1年` |
| 読み | `しょうわ50`、`へいせい10`、`れいわ5`、`たいしょう10`、`めいじ40` |
| 西暦日付 | `1998/04/12`、`1998-04-12`、`1998.4.12`、`1998年4月12日` |
| 和暦日付 | `平成10年4月12日`、`H10.4.12`、`H10/4/12` |
| 年齢 | `50歳`、`現在50歳` |

全角英数字、英字の大小、空白は正規化します。日付の区切り文字は統一してください。「50」のような0～150の裸の数字は自動確定せず候補を表示し、終了済みの元号の存在しない年や、現時点より未来の和暦年は候補に出しません。明示的な未来年入力は受け付けます。

## 計算仕様と仕様書の補足

### 対応範囲

西暦の入力範囲は **1000～2200年**、年齢入力は **0～150歳**です。企画書の「明治以前も西暦表示」と「1000～3000は西暦と認識」を踏まえ、明治以前の西暦計算を許可し、上限は初期版の2200年に統一しました。1868年より前は和暦対象外と表示します。年表は2200年までで打ち切ります。学年の参考年が2200年を超える場合は西暦だけを表示します。

### 和暦

元号データは `src/era/eras.ts` に集約し、開始日・終了日を持ちます。終了日はその日を含みます。

| 元号 | 開始日 | 終了日 |
| --- | --- | --- |
| 明治 | 1868-01-25 | 1912-07-29 |
| 大正 | 1912-07-30 | 1926-12-24 |
| 昭和 | 1926-12-25 | 1989-01-07 |
| 平成 | 1989-01-08 | 2019-04-30 |
| 令和 | 2019-05-01 | 未定 |

**明治の開始日は企画書の指定値を採用した、便宜上の境界です。旧暦をグレゴリオ暦へ換算した歴史上の日付を保証するものではありません。** 本アプリの日付はグレゴリオ暦として計算し、明治初期の入力時には旧暦非対応の注記を表示します。

- 年だけの `1989` は `昭和64年 / 平成元年`、`2019` は `平成31年 / 令和元年` と表示します。
- `昭和64年` のように元号が指定されている場合、指定元号を保持し「1989年1月1日～1月7日の7日間」を添えます。
- 日付がある場合はその日の元号を1つ表示します。指定元号の期間外の日付はエラーです。
- 令和の未来年を仮換算する場合は、将来の改元を考慮していない旨を表示します。

### 満年齢

- 生年月日あり：`基準年 - 生年` から、基準日の誕生日がまだなら1を引きます。
- 生年だけ：`基準年 - 生年 - 1 ～ 基準年 - 生年`。負の下限は0に丸めます。
- 出生前の基準日・年は「出生前」。負の年齢は表示しません。
- 生年のみの年齢幅は、基準日を指定しても誕生日不明のため仕様書どおり年単位の幅を保持します。
- 指定年だけでは観測日が不明なため「この年に何歳？」も幅表示。生年月日が既知ならその年の1月1日～12月31日の年齢を使い、1月1日生まれなど年内の年齢が一定なら単一表示です。日付を入力し、生年月日も既知なら満年齢を返します。
- 2月29日生まれは、平年では3月1日に年齢を加算します。到達日計算も同じです。法律上の到達時刻を判定する機能ではありません。
- 年齢→生年：`基準年 - 年齢 - 1 ～ 基準年 - 年齢` の候補。生年の候補選択後は誕生日不明として扱います。
- 到達年齢：`生年 + 年齢`。生年月日ありなら到達日を返します。
- 今日の日付は端末のローカル日時を使用します。別タブから戻った際に更新します。

### 2～4人の年齢比較

「年齢比較」タブで、それぞれの生年・生年月日を入力します。西暦・和暦・元号略称・全角入力に対応します。呼び名は「呼び名を付ける」を開いて任意で入力できます。「変換の入力を1人目に使う」から単独の入力を取り込めます。

- 最初は2人。追加・削除で2～4人の範囲に変更できます。途中の人を削除しても、残る人の呼び名・入力値は保持します。
- 比較の基準日は、他のタブの「年齢の基準日」と双方向に連動します。
- 上部に各人の年齢と、入力済み・未入力・要確認の人数を表示します。一覧の人を選ぶと、その入力欄へ移動します。
- 各人の満年齢と、全組み合わせ（2人＝1組、3人＝3組、4人＝6組）の差を表示します。
- 差は **同じ基準日時点の整数の満年齢の差** です。生年月日どうしの年月日間隔や単なる生年の引き算ではありません。誕生日をまたぐと変化する場合があります。
- 生年のみの人がいる場合は差にも幅を付けます。例えば58～59歳と50～51歳は7～9歳差。同じ生年で誕生日不明なら0～1歳差です。
- 生年月日が既知で同じ満年齢なら0歳差です。出生前の人を含む組は「出生前のため比較できません」と表示します。
- 年齢だけの入力（例：50歳）から生年を確定できないため、比較欄には生年または生年月日を入力します。
- 全員の入力が有効になるまで組み合わせの比較とコピーを無効にします。基準日が無効な間も古い計算結果は表示しません。
- 全員の入力が有効になると、入力欄より上に全組み合わせの差を表示します。各人の入力・削除・呼び名の編集はその下で行えます。
- 比較結果のコピーには基準日、各人の呼び名・生年・年齢、全組の差、幅表示の注記を含めます。
- 複数人の入力も保存・外部送信しません。既存の共有URLには含めず、再読み込みすると2人分の空欄に戻ります。

### 年表・学年・干支

- 年表の通常行は **その年の誕生日に迎える満年齢**。「現在」行は今日時点の満年齢／幅です。
- 年表の現在行は上の基準日を変更しても今日のままです。同じ年の節目と現在は1行にまとめます。
- 年表の上部に今日の日付を表示し、「現在」行にも月日を添えます。
- 学年は4月2日～翌年4月1日を同じ集団とします。1月1日～4月1日生まれは前年の年度生。
- 小学校入学＝年度生+7、中学＝+13、高校＝+16、高校卒業目安＝+19の3月。
- 学年は現在の通常の進級を前提とする参考値で、歴史的な学制、就学猶予、留年、個別の進路を考慮しません。
- 干支は十二支のみで、西暦年に対応します。旧暦の年境界や十干は扱いません。2000年＝辰。
- 長寿の節目は満年齢での参考表示。20歳のラベルは「二十歳」で、成人資格の判定には使用しません。

### エラーの区別

パーサーは空欄、曖昧な数値、入力不明、存在しない日付、無効な元号年・元号期間、範囲外を区別します。未来の日付は変換自体を可能にし、注記を表示します。入力文字列はHTMLに直接挿入せずエスケープします。

## プライバシーと共有

- 入力内容・生年月日・履歴はlocalStorageに保存しません。
- localStorageに保存するのは `koyomi.theme` と `koyomi.timelineMode` のみです。保存できないブラウザーでも動作します。
- 共有操作はURLをクリップボードにコピーするだけです。アプリから第三者への送信は行いません。
- URLの例：`?birth=1967`、`?birth=1967-10-15&ref=2026-09-25`。和暦や年齢文字列も保持できます。
- **共有URLには入力内容と基準日が含まれます。** URLを開くとブラウザーの履歴や配信元のアクセスログに残る場合があります。共有先にも入力内容が伝わります。
- コピーボタン付近に、URLに含まれる実際の入力内容と基準日を表示します。複数人比較はURLに含めません。年齢だけを伝える場合は、年齢の横のコピーアイコンを使えます。
- Service Workerが保存するのはアプリ本体・CSS・アイコンだけです。入力値や共有URLをキャッシュキーとして保存しません。

## PWAとオフライン

`npm run build` でアセット一覧を含む `dist/sw.js` を生成します。Service Workerは本番ビルドでのみ登録します。HTTPS（またはlocalhost）で最初に読み込み、フッターに「オフラインでも利用できます」が表示された後は、ネットワークがなくても再表示・計算できます。

`dist/` の内容を任意の静的ホスティングに配置できます。`base: './'` のためサブディレクトリ配信にも対応します。HTMLと `sw.js` は更新を確認できるキャッシュ設定にしてください。`file://` での直接起動は対象外です。ホーム画面への追加操作はブラウザー・OSによって異なります。

manifestと192px／512pxのPNGアイコン、SVGアイコンを同梱しています。PNGを再生成する場合はWindows PowerShellで `./scripts/generate-icons.ps1` を実行します。

## ソース構成

```text
src/
  era/       元号データ・相互変換・和暦パーサー
  age/       満年齢・生年逆算・学年
  parser/    入力正規化・型・総合パーサー
  timeline/  DOMに依存しない年表生成
  ui/        画面構成・タブ、結果・年表・複数人比較の描画、アイコン、コピー通知
  utils/     日付の検証・整形
  main.ts    UIイベント・状態・設定・PWA登録
  style.css  レスポンシブ・ダークモード・印刷スタイル
tests/       仕様書100件と追加の境界テスト
public/      manifest・アイコン
```

## 検証

仕様書の各ケースには元の番号（#1～#100）を付けています。追加テストは、改元年の複数元号、昭和64年の期間、曖昧入力、入力範囲、不正文字、出生前、2月29日の年齢、年表の重複・上限、干支などです。

2026年10月26日の検証では173件すべて成功し、型検査・本番ビルドも成功しています。計算条件の表示について4件を追加しました。ブラウザーでの確認項目と未検証の環境は [QA.md](./QA.md) に記録しています。

使用した開発ツールの公式資料：[Vite](https://vite.dev/guide/)、[Vitest](https://vitest.dev/guide/)。

## 注意事項

本ツールは日付・年齢確認を補助するための簡易ツールです。

正式な行政手続、法律上の年齢判定、資格要件等については、各制度を所管する公的機関の情報をご確認ください。

将来の改元については予測できないため、未来の日付の和暦表示は現在の元号が継続すると仮定する場合があります。
